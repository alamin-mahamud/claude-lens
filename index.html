Claude Code writes structured data to ~/.claude/ as you work. Claude Lens reads those files locally and aggregates them into the sections below. Nothing leaves your machine.
history.jsonl
Every prompt you send — timestamp, project, session ID, display text.
Feeds: SummaryPrompt HistoryPatterns
projects/*/[id].jsonl
Full conversation logs — assistant messages with token usage, tool calls, and model info per turn.
Feeds: Daily CostsTool CallsSession ThreadsPatterns
stats-cache.json
Claude Code's own aggregated counters — updated automatically after each session.
Feeds: Summary (supplementary)
sessions/*.json
Session metadata — IDs, project links, creation timestamps.
Feeds: Session Thread View
How sections connect: The Summary totals come from aggregating all project JSONL files by date — the same data that drives Daily Costs. Cache Hit Rate is computed as cacheRead ÷ (input + cacheRead + cacheCreate). Pattern Insights analyze trends across all of this data to surface personalized recommendations. Session Threads read the same JSONL files as Daily Costs but filter by session ID to show conversation turns.
